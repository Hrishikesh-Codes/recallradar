# @recallradar/web

The RecallRadar web app (Next.js 16, App Router). See the [root README](../../README.md) to run
the whole stack, and [docs/DESIGN.md](../../docs/DESIGN.md) for the design system.

```bash
pnpm dev          # http://localhost:3000
pnpm test         # Vitest unit tests
pnpm build && pnpm e2e   # Playwright against the production build
```
